# RM 2026 步兵下位机

基于 [An-OrangeMan/2026-RoboMaster-Infantry](https://github.com/An-OrangeMan/2026-RoboMaster-Infantry) 的步兵下位机代码，接入本队[大小符视觉模块](https://github.com/thekfjie/RM_BUFF_V2)。原项目的提交历史保留在 Git 中。本仓库含固件源码和现有 Keil 工程；团队烧录前需确认实际使用 `MDK-ARM/` 还是 `ShaoBing1/MDK-ARM/`，两套工程对应的 `application/` 都已同步修改。

## 视觉通信

上位机通过 USART1（115200/8N1）与下位机通信。反馈帧 `0x5A` 为 28 字节，仍提供 INS 姿态；控制帧均为 48 字节，末尾使用原有 CRC16：

| 上位机模式 | 控制帧 | 下位机行为 |
|---|---|---|
| 打装甲板 | `0xA5` | 保留装甲板状态、飞行时间和运动外推路径 |
| 打大小符 | `0xA6` | 使用上位机已经预测的绝对 INS yaw/pitch，不再按装甲板模型重复预测或重力补偿 |

`0xA6` 帧包含有效位、绝对 yaw、绝对 pitch、预测时域、保留字段和 CRC16。接收端在第 48 字节到达时立即校验 CRC；帧体中出现帧头字节不会中断接收。下位机按 CRC、目标有效位和最后收包时间判断瞄准状态，超过 160 ms 无有效命令便退出目标有效状态。云台角差继续受现有限幅控制；yaw 使用环绕角差处理 ±π 边界。

模式由[视觉串口桥](https://github.com/thekfjie/RM_BUFF_V2/blob/main/docs/BUFF_INFANTRY_SERIAL.md)在同一物理串口上选择，固件按最近收到的命令帧头走对应路径。遥控器保持云台接管权；这份改动没有增加自动开火。装甲板与大小符预测不可在两侧重复执行；大小符完整弹道、枪口偏置和发射许可尚未在本固件中实现。

## 联调边界

此代码经过协议与控制路径静态核对，尚未在目标 Keil 环境编译、串口实测或上车验证。首次联调应先在无弹丸、受限云台行程下检查：

1. `0x5A` 姿态反馈的坐标方向与相机 TF；`0xA5` 装甲板路径是否维持原行为。
2. `0xA6` 的 yaw/pitch 正负号、±π 跨界、两模式切换及遥控器接管。
3. 无效帧、CRC 错误和断流超过 160 ms 时，云台是否退出目标跟踪。

视觉侧部署、预测时域和 PnP 参数以[视觉仓库说明](https://github.com/thekfjie/RM_BUFF_V2)为准。串口联通不代表大小符命中率已经验证。
